[SkiPri.com](https://SkiPri.fr) est une plateforme de comparaison des prix des forfaits de ski entre les stations françaises, avec une interface de filtrage pour trouver les meilleures offres et un espace d'administration pour gérer les données des stations et superviser le pipeline de scraping.

Ce projet couvre l'ensemble de la chaîne : collecte automatisée de données depuis plusieurs sources, API backend sécurisée, et interface web statique déployée sur AWS.

# Fonctionnalités

- Interface de comparaison des prix des forfaits de ski, filtrable par station
- Espace d'administration (AWS Cognito) pour gérer les données des stations et suivre le pipeline de scraping
- Pipeline de collecte de données automatisé, agrégeant plusieurs sources 
- API REST sécurisée avec validation des tokens côté serveur

# Architecture & technologies

- **Frontend** : Next.js 16 (React 19), Tailwind CSS 4, export statique
- **Backend** : FastAPI (Python), SQLAlchemy 2, PostgreSQL
- **Authentification** : AWS Cognito
- **Base de données** : PostgreSQL
- **Collecte de données** : scrapers Python (BeautifulSoup, pdfplumber, pandas, httpx)
- **Hébergement** : frontend sur S3 + CloudFront, backend sur AWS

# Points clés

- Conception d'un pipeline de scraping multi-sources (extraction PDF, parsing, staging et synchronisation vers des tables canoniques avec gestion des alias de noms de stations)
- Développement du backend FastAPI avec authentification Cognito et séparation claire entre lecture publique et administration
- Modélisation de la base de données pour les stations, prix et sources de données
- Mise en place de l'infrastructure AWS (S3, CloudFront) pour un export statique performant
