Within a four-person Infrastructure team, I contributed to modernization, security, and migration projects for the virtualization platforms, Citrix infrastructure, and VMware environments.

# Mission

Administered and evolved the Citrix Virtual Apps & Desktops infrastructure as well as the VMware virtualization platform supporting the company's user and server environments.

Contributed to numerous projects related to Record's integration into the ASSA ABLOY group: Active Directory migration, infrastructure renewal, server hardening, deployment industrialization, and improving technical documentation.

In parallel, provided level 3 support for complex incidents related to systems and virtualization infrastructure.
