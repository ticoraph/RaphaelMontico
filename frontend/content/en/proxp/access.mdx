# Position type

Permanent contract (CDI)

# Location

Annecy, France (on-site work across Auvergne-Rhône-Alpes)

# The company

Access Ingénierie Informatique (A2i), part of the Access Group, is an IT services company specializing in the integration, administration, and maintenance of IT infrastructure for SMEs, local authorities, and public institutions. Teams work directly on client sites to deploy, operate, and maintain their information systems.

# Mission

[https://www.access-group.fr/](https://www.access-group.fr/)

Work on-site for the company's clients on IT infrastructure installation, administration, and maintenance services. Carry out technical interventions on-site, deploy Windows servers, support end users, and help keep IT environments operational.

Interventions took place daily at client sites, mainly across Savoie, Haute-Savoie, Isère, and Ain, using a company vehicle.

# Skills & technologies

- Windows Server
- Active Directory
- DNS
- DHCP
- TCP/IP networking
- Server installation
- Workstation deployment
- User support
- Incident diagnosis and resolution
- On-site interventions
- Client relations

# Key achievements

- Installed and configured Windows servers at client sites.
- Contributed to the administration and maintenance of IT infrastructure in a professional environment.
- Carried out technical interventions across sites in Savoie, Haute-Savoie, Isère, and Ain.
- Supported users and resolved hardware, software, and network incidents.
- Developed expertise in Microsoft environments and on-site managed services.
