# Overview

This professional bachelor's degree trains systems and network administrators capable of designing, deploying, administering, and securing enterprise IT infrastructures. The program focuses on system operation, network architectures, infrastructure services, cybersecurity, and technical project management. It is designed to meet the needs of companies seeking operational profiles capable of working in production environments.

# Skills Acquired

- Design a network architecture that meets the functional, technical, and economic needs of an organization.
- Install, administer, and maintain systems and network infrastructures.
- Deploy and secure enterprise services (DNS, DHCP, Active Directory, LDAP, firewalls, VPN, etc.).
- Implement security policies and ensure infrastructure protection.
- Monitor the performance, availability, and continuity of IT services.
- Automate administration tasks using scripts.
- Diagnose and resolve system and network incidents.
- Participate in IT project management and the drafting of technical documentation.
